## 🔍 常见错误提示对照表

| Toast提示 | Logcat日志 | 可能原因 | 解决方法 |
|----------|-----------|---------|---------|
| `文件不存在` | `W/...: 文件不存在` | 已被删除 | 正常，无需处理 |
| `文件无法读取（权限不足）` | `E/...: 可读: false` | 无READ权限 | 检查应用权限 |
| `文件无法写入（权限不足，无法删除）` | `E/...: 可写: false` | 无WRITE权限 | 授予存储权限 |
| `父目录无写权限` | `E/...: 父目录可写: false` | 目录被保护 | 更换存储位置 |
| `删除失败（可能被其他程序占用或系统保护）` | `E/...: 删除失败` | 文件占用/保护 | 关闭占用应用 |
| `安全异常：权限被拒绝` | `E/...: SecurityException` | 系统级限制 | 检查MANAGE_EXTERNAL_STORAGE |
| `删除异常：XXX` | `E/...: 异常堆栈` | 未知错误 | 查看详细堆栈 |

## 🐛 问题排查

### 如果看不到Toast提示

1. 检查系统通知权限是否开启
2. 检查应用是否在后台
3. 使用Logcat查看日志

### 如果Logcat没有输出

```bash
# 检查设备连接
adb devices

# 重启adb
adb kill-server
adb start-server

# 确认应用在运行
adb shell ps | grep androidx.media3
```

### 如果删除失败率高

1. 检查应用权限：设置 → 应用 → 权限
2. 检查存储权限：需要"文件和媒体"权限
3. 对于Android 11+：
   ```bash
   # 授予MANAGE_EXTERNAL_STORAGE权限
   adb shell appops set androidx.media3.demo MANAGE_EXTERNAL_STORAGE allow
   ```

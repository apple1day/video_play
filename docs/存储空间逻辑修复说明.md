# 存储空间逻辑修复说明

## 🐛 问题描述

**修复前的错误逻辑：**
- **内部存储** → 指向 `/data` 目录（系统目录，用户无法访问，没有视频文件）
- **外部存储** → 指向 `/storage/emulated/0`（实际是手机本机存储，用户视频所在位置）

**问题现象：**
- 点击"内部存储"看不到任何视频
- 必须切换到"外部存储"才能看到手机本机的视频
- 用户体验困惑：手机本机视频反而在"外部"

---

## ✅ 修复后的正确逻辑

**修复后：**
- **内部存储（手机）** → `/storage/emulated/0` → 手机本机存储，用户视频所在位置 ✓
- **外部存储（U盘/SD卡）** → `/storage/xxxx` → 真正的外部设备（U盘、SD卡等）✓

#### 修改前：
```java
public static List<File> getStorageDirectories(Context context) {
    List<File> directories = new ArrayList<>();
    
    // ❌ 错误：指向系统目录 /data
    File internalStorage = Environment.getDataDirectory();
    if (internalStorage != null && internalStorage.exists()) {
        directories.add(internalStorage);
    }
    
    // ❌ 错误：把手机本机存储当作"外部"

    if (externalStorage != null && externalStorage.exists()) {
        directories.add(externalStorage);
    }
    ...
}
```

#### 修改后：
```java
public static List<File> getStorageDirectories(Context context) {
    List<File> directories = new ArrayList<>();
    
    // ✅ 正确：首先添加手机本机存储（内部存储）
    File primaryStorage = Environment.getExternalStorageDirectory();
    if (primaryStorage != null && primaryStorage.exists()) {
        directories.add(primaryStorage);
    }
    
    // ✅ 正确：然后添加真正的外部设备（U盘、SD卡）
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.R) {
        directories.addAll(getRemovableStorageDirectoriesApi30(context));
    } else {
        directories.addAll(getRemovableStorageDirectories(context));
    }
    
    return directories;
}
```

### 2. 新增辅助方法 - 区分存储类型

```java
/**
 * 判断指定目录是否是主存储（手机本机存储）
 */
public static boolean isPrimaryStorage(File directory) {
    File primaryStorage = Environment.getExternalStorageDirectory();
    return directory.equals(primaryStorage);
}

/**
 * 判断指定目录是否是外部存储设备（U盘、SD卡等）
 */
public static boolean isRemovableStorage(File directory) {
    return !isPrimaryStorage(directory);
}

/**
 * 获取存储设备的显示名称
 */
public static String getStorageDisplayName(File directory) {
    if (isPrimaryStorage(directory)) {
        return "内部存储";  // 手机本机存储
    } else {
        String path = directory.getAbsolutePath();
        String name = directory.getName();
        
        // 识别常见的外部设备类型
        if (name.toUpperCase().contains("USB") || path.contains("usb")) {
            return "U盘";
        } else if (name.toLowerCase().contains("sdcard") || name.toUpperCase().contains("SD")) {
            return "SD卡";
        } else {
            return "外部存储";
        }
    }
}
```

### 3. Android 11+ (API 30) 外部设备获取

```java
@RequiresApi(api = Build.VERSION_CODES.R)
private static List<File> getRemovableStorageDirectoriesApi30(Context context) {
    List<File> directories = new ArrayList<>();
    StorageManager storageManager = context.getSystemService(StorageManager.class);
    File primaryStorage = Environment.getExternalStorageDirectory();
    
    if (storageManager != null) {
        List<StorageVolume> volumes = storageManager.getStorageVolumes();
        for (StorageVolume volume : volumes) {
            // ✅ 只添加已挂载的、非主存储的卷（即外部设备）
            if (volume.getState().equals(Environment.MEDIA_MOUNTED) && !volume.isPrimary()) {
                File directory = volume.getDirectory();
                if (directory != null && directory.exists() && !directory.equals(primaryStorage)) {
                    directories.add(directory);
                }
            }
        }
    }
    return directories;
}
```

```java
private String getStorageTitle(File directory) {
    // 主存储（手机本机存储）
    File primaryStorage = Environment.getExternalStorageDirectory();
    
    if (directory.equals(primaryStorage)) {
        return "内部存储（手机）";  // ✅ 正确指向手机本机
    } else {
        // 外部存储设备（U盘、SD卡等）
        String path = directory.getAbsolutePath();
        if (path.contains("/storage/")) {
            String[] parts = path.split("/");
            if (parts.length > 2) {
                String deviceName = parts[parts.length - 1];
                // 识别常见的外部设备类型
                if (deviceName.toUpperCase().contains("USB")) {
                    return "U盘: " + deviceName;
                } else if (deviceName.contains("sdcard") || deviceName.contains("SD")) {
                    return "SD卡: " + deviceName;
                } else {
                    return "外部存储: " + deviceName;
                }
            }
        }
        return "外部存储: " + directory.getName();
    }
}
```

## 🔍 技术细节

### Android存储路径说明

| 路径 | 说明 | 用户可访问 | 视频存放位置 |
|-----|------|-----------|------------|
| `/data` | 系统数据目录 | ❌ 否 | ❌ 不存放 |
| `/storage/emulated/0` | 主存储（手机本机） | ✅ 是 | ✅ 是 |
| `/sdcard` | 符号链接 → `/storage/emulated/0` | ✅ 是 | ✅ 是 |
| `/storage/XXXX-YYYY` | 外部设备（U盘、SD卡） | ✅ 是 | ✅ 是 |

### Environment API 说明

```java
// 返回 /data（系统目录，不适合作为用户内部存储）
Environment.getDataDirectory()

// 返回 /storage/emulated/0（实际的手机本机存储）
Environment.getExternalStorageDirectory()
```

**注意**：虽然 `getExternalStorageDirectory()` 名字叫 "External"，但它实际返回的是手机本机的主存储，不是真正的外部设备！这是Android API的历史遗留命名问题。

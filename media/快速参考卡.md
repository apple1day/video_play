## 🔑 关键配置

### build.gradle 核心
```gradle
versionName '3.1.0.0'
versionCode 3100
minSdkVersion 25
targetSdkVersion 36

abiFilters 'armeabi-v7a', 'arm64-v8a'  // 仅ARM
multiDexEnabled true                    // 多DEX
viewBinding = true                      // ViewBinding
minifyEnabled true                      // 混淆
shrinkResources true                    // 资源压缩
```

### ProGuard 关键规则
```proguard
-optimizationpasses 5                   # 5次优化
-keepattributes SourceFile,LineNumberTable  # 保留行号
-assumenosideeffects class android.util.Log # 移除日志
```

## 🚨 常见问题

### Q1: 构建失败
```bash
# 解决方案
./gradlew clean
rm -rf .gradle/ build/
./gradlew build --refresh-dependencies
```

### Q2: APK 体积异常
```bash
# 检查 APK 组成
unzip -l media-release.apk
# 查看 lib/ 目录是否有多余架构
```

### Q3: 运行时崩溃
```bash
# 查看崩溃日志
adb logcat | grep -E "(AndroidRuntime|FATAL)"
# 检查 ProGuard 是否过度混淆
```

### Q4: 内存泄漏
```bash
# 安装 Debug 版本（自动集成 LeakCanary）
./gradlew assembleDebug
adb install media-debug.apk
# 使用应用，LeakCanary 会自动检测并显示泄漏
```

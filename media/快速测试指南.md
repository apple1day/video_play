# 📱 文件共享功能 - 快速测试指南

## 🚀 一分钟快速测试

### 第 1 步：编译安装应用
```bash
# 在 Android Studio 中点击 Run 按钮
# 或使用命令行
./gradlew installDebug
```

### 第 2 步：创建测试文件
应用启动后会自动创建共享目录：
```
/sdcard/Android/data/com.anxiong666.www/files/
```

### 第 3 步：USB 连接测试

#### Windows 用户：
1. 用 USB 线连接 Android 设备
2. 设备通知栏选择 **"文件传输"** 模式
3. 打开 **"文件资源管理器"**
4. 找到设备名称（例如：Pixel 6）
5. 依次进入：
   ```
   内部存储 → Android → data → com.anxiong666.www → files
   ```
6. ✅ 看到 `files` 文件夹即表示成功！

#### Mac 用户：
1. 下载并安装 [Android File Transfer](https://www.android.com/filetransfer/)
2. USB 连接设备
3. 自动打开 Android File Transfer
4. 导航到：
   ```
   Internal Storage → Android → data → com.anxiong666.www → files
   ```
5. ✅ 看到应用文件夹即表示成功！

## 🔍 故障排查

### 问题 1：电脑上看不到应用文件夹

**可能原因：**
1. USB 连接模式不是 "文件传输"
2. 设备屏幕锁定
3. 应用未运行过（目录未创建）
4. 路径错误

**解决方法：**
```bash
# 使用 ADB 检查目录是否存在
adb shell ls -la /sdcard/Android/data/com.anxiong666.www/files/

# 如果目录不存在，使用 ADB 创建
adb shell mkdir -p /sdcard/Android/data/com.anxiong666.www/files/Videos

# 推送测试文件
adb push test.mp4 /sdcard/Android/data/com.anxiong666.www/files/Videos/
```

---

### 问题 2：文件导入后应用看不到

**可能原因：**
1. 文件扫描未完成
2. 文件格式不支持
3. 权限问题

**解决方法：**
1. 在应用中下拉刷新
2. 检查文件是否在正确目录
3. 查看 Logcat 日志：
```bash
adb logcat | grep "FileUtils"
adb logcat | grep "HomeFragment"
```

---

### 问题 3：DocumentsProvider 不显示

**可能原因：**
1. Manifest 配置错误
2. DocumentsProvider 实现有误
3. 系统版本不支持

**解决方法：**
```bash
# 检查 Provider 是否注册
adb shell dumpsys package com.anxiong666.www | grep "Provider"

# 查看 Provider 详细信息
adb shell content query --uri content://com.anxiong666.www.documents/root
```

---

### 问题 4：FileProvider 分享失败

**可能原因：**
1. `file_paths.xml` 配置错误
2. 文件不在配置的路径中
3. Authority 不匹配

**解决方法：**
1. 检查 Logcat 错误日志
2. 确认 Authority 为：`com.anxiong666.www.fileprovider`
3. 验证文件路径在 `file_paths.xml` 配置范围内

## 🧩 集成测试代码

### 在 MainActivity 添加测试按钮

```java
// 在 MainActivity.onCreate() 中添加
Button testButton = new Button(this);
testButton.setText("测试文件共享");
testButton.setOnClickListener(v -> testFileSharing());

// 添加测试方法
private void testFileSharing() {
    StringBuilder result = new StringBuilder("文件共享功能测试：\n\n");
    
    // 1. 检查功能是否启用
    boolean isEnabled = FileShareHelper.isFileSharingEnabled(this);
    result.append("1. FileProvider 状态: ")
          .append(isEnabled ? "✓ 已启用" : "✗ 未启用")
          .append("\n\n");
    
    // 2. 检查共享目录
    File sharedDir = FileShareHelper.getSharedDirectory(this);
    result.append("2. 共享目录: \n")
          .append(sharedDir != null ? sharedDir.getAbsolutePath() : "null")
          .append("\n")
          .append("   存在: ").append(sharedDir != null && sharedDir.exists() ? "是" : "否")
          .append("\n")
          .append("   可读: ").append(sharedDir != null && sharedDir.canRead() ? "是" : "否")
          .append("\n")
          .append("   可写: ").append(sharedDir != null && sharedDir.canWrite() ? "是" : "否")
          .append("\n\n");
    
    // 3. 创建测试目录
    File videosDir = FileShareHelper.getVideosDirectory(this);
    result.append("3. 视频目录: \n")
          .append(videosDir.getAbsolutePath())
          .append("\n   状态: ")
          .append(videosDir.exists() ? "✓ 已创建" : "✗ 不存在")
          .append("\n\n");
    
    // 4. 列出现有文件
    File[] files = sharedDir.listFiles();
    result.append("4. 现有文件数: ")
          .append(files != null ? files.length : 0)
          .append("\n");
    
    if (files != null && files.length > 0) {
        result.append("   文件列表:\n");
        for (int i = 0; i < Math.min(5, files.length); i++) {
            result.append("   - ").append(files[i].getName()).append("\n");
        }
        if (files.length > 5) {
            result.append("   ... 还有 ").append(files.length - 5).append(" 个文件\n");
        }
    }
    
    // 显示结果
    new AlertDialog.Builder(this)
        .setTitle("测试结果")
        .setMessage(result.toString())
        .setPositiveButton("确定", null)
        .setNeutralButton("复制路径", (dialog, which) -> {
            ClipboardManager clipboard = (ClipboardManager) getSystemService(CLIPBOARD_SERVICE);
            ClipData clip = ClipData.newPlainText("路径", sharedDir.getAbsolutePath());
            clipboard.setPrimaryClip(clip);
            Toast.makeText(this, "路径已复制", Toast.LENGTH_SHORT).show();
        })
        .show();
}
```

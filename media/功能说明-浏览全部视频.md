# 📂 新功能：浏览手机所有视频

## 🎯 功能说明

在 Home 页面新增了一个醒目的"浏览手机所有视频"按钮，点击后会打开一个新的页面，显示手机中所有存储位置的视频文件。

---

## ✅ 已实现的功能

### 1. **一键浏览按钮**
- 位置：Home 页面顶部（搜索框下方）
- 样式：蓝色背景，白色文字，带图标
- 文字：📂 浏览手机所有视频

### 2. **全视频列表页面**
- 自动扫描所有存储设备（内部存储 + 外部存储 + U盘）
- 按时间降序排序（最新的在前）
- 支持下拉刷新
- 显示视频数量统计

### 3. **视频播放功能**
- 点击任意视频直接播放
- 支持连续播放（自动加载下一个）
- 支持播放列表导航

### 4. **权限管理**
- 自动检查存储权限
- 无权限时自动请求
- 权限拒绝时友好提示

### 2. 新增 Activity (AllVideosActivity.java)
```java
public class AllVideosActivity extends AppCompatActivity {
    // 扫描所有存储设备的视频
    private void loadAllVideos() {
        List<File> storageDirectories = FileUtils.getStorageDirectories(this);
        List<FileItem> videos = FileUtils.scanAllFiles(
            storageDirectories, 
            FileItem.FileType.VIDEO
        );
        // 按时间降序排序
        Collections.sort(videos, (o1, o2) -> 
            Long.compare(o2.getLastModified(), o1.getLastModified())
        );
    }
}
```

### 3. HomeFragment 点击事件
```java
private void setupBrowseAllVideosButton() {
    browseAllVideosButton.setOnClickListener(v -> {
        // 检查权限
        if (!PermissionHelper.hasMediaPermissions(getActivity())) {
            PermissionHelper.requestMediaPermissions(getActivity());
            return;
        }
        
        // 打开全部视频页面
        Intent intent = new Intent(getContext(), AllVideosActivity.class);
        startActivity(intent);
    });
}
```

new Thread(() -> {

        adapter.updateFiles(videos);
        videoCountText.setText("找到 " + videos.size() + " 个视频");
    });
}).start();

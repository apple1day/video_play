# Android视频播放器应用 - 功能说明

## 📱 应用架构

### 主界面结构（MainActivity）
采用 **ViewPager2 + TabLayout** 的双Tab设计：
- **首页（HomeFragment）**: 显示所有视频信息
- **更多（MoreFragment）**: 访问本地存储和外置U盘文件夹

---

## 🏠 首页功能（HomeFragment）

### 核心功能
1. **视频展示**
   - 显示所有存储设备中的视频文件
   - 支持列表视图和网格视图切换
   - 显示视频缩略图、名称、大小、时长等信息

2. **存储切换**
   - 内部存储：设备内置存储空间
   - 外部存储：SD卡、U盘等外置存储设备
   - 下拉菜单快速切换

3. **排序功能**
   - 按时间排序（新→旧 / 旧→新）
   - 按大小排序（大→小 / 小→大）
   - 点击按钮切换升序/降序

4. **视图模式**
   - 列表视图：详细信息显示
   - 网格视图：2列网格布局，紧凑展示

5. **下拉刷新**
   - 支持下拉刷新重新扫描文件
   - 多彩刷新动画提示

6. **文件操作**
   - **单选模式**：点击视频直接播放
   - **多选模式**：长按进入多选，可批量操作
     - 全选/取消全选
     - 选择所有收藏的视频
     - 选择所有已观看的视频
     - 选择所有待删除的视频
     - 批量删除选中文件

7. **已观看管理** 🆕
   - **自动标记**：播放进度超过80%自动标记为已观看
   - **断点续播**：下次观看自动从上次位置继续
   - **视觉标识**：列表中显示绿色勾图标标记已观看
   - **多选支持**：可批量选择已观看视频进行管理
   - **智能记录**：记录每个视频的播放进度和观看时间

8. **播放功能**
   - 点击视频自动进入播放器
   - 传递当前排序后的视频列表
   - 支持连续播放（播放完自动播放下一个）

### 数据管理
- **allVideoFiles**: 存储所有扫描到的视频（用于播放列表）
- **displayedFiles**: 当前显示的视频（经过排序和筛选）
- **支持权限检查**：自动请求存储访问权限

---

## 📂 更多功能（MoreFragment）

### 核心功能
1. **文件浏览器**
   - 浏览所有存储设备的文件夹结构
   - 显示内部存储和外置U盘根目录
   - 支持多级目录导航

2. **存储设备列表**
   ```
   ┌─────────────────────────┐
   │  存储根目录              │
   ├─────────────────────────┤
   │  📁 内部存储 (/storage/emulated/0)
   │  📁 SD卡 (/storage/XXXX-XXXX)
   │  💾 U盘1 (/storage/usb/...)
   │  💾 U盘2 (/storage/usb/...)
   └─────────────────────────┘
   ```

3. **目录导航**
   - 点击文件夹进入子目录
   - 返回按钮回到上级目录
   - 显示当前路径
   - 历史记录栈管理

4. **文件类型支持**
   - 📹 视频文件：点击播放
   - 🎵 音频文件：显示信息
   - 🖼️ 图片文件：点击预览
   - 📄 其他文件：显示文件信息

5. **文件操作**（长按文件）
   - ⭐ 收藏/取消收藏
   - 🗑️ 标记待删除/取消待删除
   - ❌ 立即删除
   - ℹ️ 查看文件信息

6. **设置入口**
   - 右上角设置按钮进入设置页面

7. **实时刷新**
   - 文件删除后自动刷新列表
   - 返回页面时自动刷新

### 特色功能
- **U盘热插拔支持**：自动检测新插入的U盘
- **多存储设备管理**：统一管理所有存储设备
- **文件夹优先排序**：文件夹始终显示在文件前面
- **隐藏文件过滤**：自动隐藏系统隐藏文件

## 🎬 播放器功能（PlayerActivity）

### 播放控制
- 播放/暂停
- 快进/快退
- 进度条拖拽
- 音量调节
- 亮度调节

### 智能播放功能 🆕
- **断点续播**：自动从上次观看位置继续播放
- **自动标记已观看**：播放超过80%自动标记为已观看
- **播放历史记录**：记录每个视频的播放进度
- **无缝切换**：切换视频时自动保存进度和标记状态

### 播放列表
- 从首页传入：当前排序后的视频列表
- 从更多页传入：当前文件夹的视频列表
- 支持上一个/下一个切换
- 播放完自动播放下一个

### 全屏支持
- 横屏自动全屏
- 手势控制
- 系统UI自动隐藏

## 🔧 build.gradle 配置优化

### 版本信息
```gradle
versionName '3.0.3.0'
versionCode 3030
minSdkVersion 25
targetSdkVersion 36
```

### 新增配置

#### 1. NDK ABI过滤
```gradle
ndk {
    abiFilters 'armeabi-v7a', 'arm64-v8a', 'x86', 'x86_64'
}
```
**优势**：
- 支持所有主流架构（ARM32/64, x86/64）
- 兼容99%+的Android设备
- 优化APK大小

#### 2. 画中画支持
```gradle
resValue "bool", "supports_picture_in_picture", "true"
```
**功能**：
- 支持视频播放时小窗模式
- 多任务时继续播放

#### 3. Release构建优化
```gradle
proguardFiles = [
    getDefaultProguardFile('proguard-android-optimize.txt'),
    'proguard-rules.pro'
]
zipAlignEnabled true
debuggable false
jniDebuggable false
```
**优势**：
- 代码混淆保护
- 优化APK体积
- 提升运行性能

#### 4. Debug构建配置
```gradle
debug {
    debuggable = true
    minifyEnabled false
    applicationIdSuffix '.debug'
}
```
**优势**：
- Debug和Release包可同时安装
- 便于测试和开发

#### 5. 视频播放器专用配置
```gradle
packagingOptions {
    pickFirst 'lib/**/libc++_shared.so'
    exclude 'META-INF/*'
}
```
**解决问题**：
- 避免so库重复打包冲突
- 清理无用元数据
- 减小APK体积

#### 6. 视图绑定支持（可选）
```gradle
buildFeatures {
    viewBinding = false
    dataBinding = false
}
```
**说明**：
- 当前使用findViewById方式
- 如需迁移到ViewBinding，设为true

## 📋 权限要求

### 运行时权限
```xml
<!-- 读取外部存储（Android 12及以下）-->
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />

<!-- 写入外部存储（删除功能需要）-->
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />

<!-- Android 13+ 细粒度媒体权限 -->
<uses-permission android:name="android.permission.READ_MEDIA_VIDEO" />
<uses-permission android:name="android.permission.READ_MEDIA_AUDIO" />
<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />

<!-- 管理所有文件（删除功能需要）-->
<uses-permission android:name="android.permission.MANAGE_EXTERNAL_STORAGE" />

<!-- 网络权限（播放网络视频）-->
<uses-permission android:name="android.permission.INTERNET" />
```

## 🔄 数据流转

### 首页播放流程
```
扫描视频 → 显示列表 → 点击视频 → 传递列表 → 播放器
   ↓
allVideoFiles
   ↓
displayedFiles (排序后)
   ↓
getCurrentDisplayedVideoList()
   ↓
Intent extras:
  - file_path: 当前视频路径
  - file_list: 视频列表
  - current_index: 当前索引
```

### 更多页浏览流程
```
存储根目录 → 选择设备 → 进入目录 → 浏览文件
     ↓           ↓          ↓          ↓
loadRootDirectories  navigateToDirectory  handleFileClick
     ↓                      ↓                    ↓
 显示设备列表          显示文件列表          执行操作
```

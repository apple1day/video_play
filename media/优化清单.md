## 🔧 故障排除

### 问题1: 构建失败
**症状**: Gradle 同步失败或编译错误

**解决方案**:
```bash
# 清理缓存
./gradlew clean
rm -rf .gradle/
rm -rf build/

# 重新同步
./gradlew build --refresh-dependencies
```

### 问题2: APK 无法安装
**症状**: 安装时提示签名错误

**解决方案**:
```bash
# 检查签名配置
cat keystore.properties

# 使用 debug 签名测试
./gradlew assembleDebug
```

### 问题3: 运行时崩溃
**症状**: 应用启动后立即崩溃

**解决方案**:
```bash
# 查看崩溃日志
adb logcat | grep AndroidRuntime

# 检查 ProGuard 规则
# 确保核心类未被混淆
```

### 问题4: 混淆后功能异常
**症状**: Release 版本功能不正常

**解决方案**:
```gradle
// 在 proguard-rules.pro 中添加规则
-keep class 具体的类名 { *; }

// 或暂时禁用混淆测试
minifyEnabled false
```

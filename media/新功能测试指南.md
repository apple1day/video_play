## 🔧 快速测试命令

### 安装应用
```bash
# 编译并安装
./gradlew assembleDebug
adb install -r media/build/outputs/apk/debug/media-debug.apk

# 启动应用
adb shell am start -n com.anxiong666.www.debug/.MainActivity
```

### 准备测试数据
```bash
# 推送测试视频到手机
adb push test_video.mp4 /sdcard/Movies/

# 检查视频是否存在
adb shell ls -lh /sdcard/Movies/

# 查看应用日志
adb logcat | grep "AllVideosActivity"
```

### 性能监控
```bash
# 查看内存占用
adb shell dumpsys meminfo com.anxiong666.www.debug

# 查看 CPU 占用
adb shell top -n 1 | grep anxiong

# 录制屏幕（测试流畅度）
adb shell screenrecord /sdcard/test.mp4
```

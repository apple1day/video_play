# Android 视频播放器 - 文件共享功能说明

## 📱 功能概述

已成功实现类似 iOS `UIFileSharingEnabled` 的文件共享功能！

### iOS vs Android 对比

| 功能 | iOS 实现 | Android 实现 | 状态 |
|------|---------|-------------|------|
| 电脑访问应用文件 | `UIFileSharingEnabled = YES` | `DocumentsProvider` | ✅ |
| 文件目录 | Documents 文件夹 | ExternalFilesDir | ✅ |
| 访问方式 | 访达（Finder）/ iTunes | 文件管理器 / MTP / ADB | ✅ |
| 文件列表显示 | iTunes 文件共享 | Android File Transfer | ✅ |
| 拖拽文件 | 支持 | 支持 | ✅ |
| 应用内文件访问 | 配置后自动 | 配置后自动 | ✅ |

## 🔧 已实现的配置

### 1. AndroidManifest.xml 配置

#### FileProvider（文件共享基础）
```xml
<provider
    android:name="androidx.core.content.FileProvider"
    android:authorities="${applicationId}.fileprovider"
    android:exported="false"
    android:grantUriPermissions="true">
    <meta-data
        android:name="android.support.FILE_PROVIDER_PATHS"
        android:resource="@xml/file_paths" />
</provider>
```

**作用**：
- 安全地分享文件给其他应用
- 避免暴露文件系统真实路径
- 临时授权文件访问权限

#### DocumentsProvider（电脑访问功能）⭐
```xml
<provider
    android:name=".DocumentsProvider"
    android:authorities="${applicationId}.documents"
    android:exported="true"
    android:grantUriPermissions="true"
    android:permission="android.permission.MANAGE_DOCUMENTS">
    <intent-filter>
        <action android:name="android.content.action.DOCUMENTS_PROVIDER" />
    </intent-filter>
</provider>
```

**作用**：
- **这就是 Android 版的 `UIFileSharingEnabled`！**
- 让电脑通过 USB 连接访问应用文件
- 在文件管理器中显示应用的文件夹
- 支持拖拽、复制、删除等操作

#### 文件关联（打开视频文件）
```xml
<intent-filter>
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <data android:scheme="file" />
    <data android:scheme="content" />
    <data android:mimeType="video/*" />
</intent-filter>
```

**作用**：
- 其他应用可以用本应用打开视频文件
- 在"打开方式"菜单中显示本应用

### 2. 文件路径配置（file_paths.xml）

定义应用可以共享的目录：

```xml
<!-- 应用内部存储 - Documents 目录 -->
<files-path name="internal_files" path="." />

<!-- 外部存储私有目录 - 应用专属 -->
<external-files-path name="external_files" path="." />

<!-- 视频目录 -->
<external-files-path name="movies" path="Movies/" />
<external-files-path name="videos" path="Videos/" />

<!-- 下载目录 -->
<external-files-path name="downloads" path="Download/" />

<!-- 外部存储根目录（需要权限） -->
<external-path name="external_storage" path="." />
```

**目录说明**：
- `internal_files`: `/data/data/com.anxiong666.www/files/` （不可被电脑访问）
- `external_files`: `/sdcard/Android/data/com.anxiong666.www/files/` ⭐（电脑可访问）
- `movies`: `/sdcard/Android/data/com.anxiong666.www/files/Movies/`
- `videos`: `/sdcard/Android/data/com.anxiong666.www/files/Videos/`

### 3. DocumentsProvider 实现

创建了完整的 `DocumentsProvider.java` 类：

#### 核心功能：
1. **queryRoots()** - 在文件管理器中显示应用根目录
2. **queryChildDocuments()** - 列出文件和子目录
3. **openDocument()** - 打开文件供读取/写入
4. **createDocument()** - 在电脑上创建新文件（拖入文件）
5. **deleteDocument()** - 在电脑上删除文件
6. **renameDocument()** - 在电脑上重命名文件

#### 特色功能：
- ✅ 自动排序（目录优先，按名称排序）
- ✅ 隐藏系统隐藏文件（`.` 开头的文件）
- ✅ 支持视频缩略图
- ✅ 安全检查（防止访问应用目录外的文件）
- ✅ 完整的错误处理

## 💻 电脑访问方式

### Windows 电脑

1. **USB 连接设备**
   ```
   用 USB 线连接 Android 设备
   → 设备通知栏选择"文件传输"模式
   → 打开"文件资源管理器"
   → 找到设备名称
   → 进入"内部存储" → "Android" → "data" → "com.anxiong666.www" → "files"
   ```

2. **MTP 模式**
   - 自动识别设备
   - 显示应用的文件夹
   - 支持拖拽文件

### Mac 电脑

1. **安装 Android File Transfer**
   ```
   下载：https://www.android.com/filetransfer/
   安装后运行
   → USB 连接设备
   → 自动打开 Android File Transfer
   → 导航到应用目录
   ```

2. **访问路径**
   ```
   Android File Transfer
   → Internal Storage
   → Android
   → data
   → com.anxiong666.www
   → files
   ```

### Linux 电脑

1. **使用 MTP 协议**
   ```bash
   # 安装 MTP 工具
   sudo apt install mtp-tools
   
   # 列出设备
   mtp-detect
   
   # 挂载设备
   mkdir ~/android
   jmtpfs ~/android
   
   # 访问文件
   cd ~/android/Android/data/com.anxiong666.www/files
   ```

## 🔐 权限说明

### 必需权限

```xml
<!-- 读取外部存储 -->
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />

<!-- 写入外部存储 -->
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />

<!-- Android 13+ 细粒度权限 -->
<uses-permission android:name="android.permission.READ_MEDIA_VIDEO" />
<uses-permission android:name="android.permission.READ_MEDIA_AUDIO" />
```

### DocumentsProvider 权限

```xml
<!-- 文档访问权限（系统级） -->
android:permission="android.permission.MANAGE_DOCUMENTS"
```

**注意**：
- 这是**系统权限**，不需要用户手动授予
- 当用户 USB 连接设备时，系统自动处理
- 类似 iOS 的 `UIFileSharingEnabled`，是一个**功能开关**而非隐私权限

## 🐛 常见问题

### Q1: 电脑上看不到应用文件夹？

**A**: 检查以下几点：
1. USB 连接模式是否为"文件传输"（MTP）
2. 设备是否已解锁
3. 应用是否至少运行过一次（创建目录）
4. 导航路径是否正确：`Android/data/com.anxiong666.www/files/`

### Q2: 文件拖入后应用看不到？

**A**: 
1. 在应用中下拉刷新
2. 重启应用
3. 检查文件是否在正确的目录

### Q3: Mac 上无法访问？

**A**: 
1. 安装 Android File Transfer
2. 或使用 ADB：`adb pull /sdcard/Android/data/com.anxiong666.www/files/ ~/Desktop/`

### Q4: 应用卸载后文件还在吗？

**A**: 
- **外部存储**（`ExternalFilesDir`）：卸载后**会被删除**
- 如需保留：将文件移动到公共目录（如 `Movies` 文件夹）
